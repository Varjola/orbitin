Changelog

Changes in each version, newest first. A detailed changelog is on GitHub.

Version 1.1.0

  • Interception mode added: a game about changing orbits. Burn forwards or backwards to reach a target orbit before your propellant runs out.
  • Route Planner mode added: plan routes between two satellites and compare what each costs in Δv against how long it takes.
  • Mode list: the top bar shows the current mode and opens a list of all modes and what each is for.
  • Minor bug fixes and adjustments.
