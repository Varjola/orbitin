# Contributing

Orbitin does not accept pull requests.

- **Bugs.** Open a [GitHub issue](https://github.com/Varjola/orbitin/issues/new/choose)
  with the bug report form. Include what you did, what you expected, what
  happened, the browser and device, and a scene link that shows the problem
  if you have one (Share, then Copy link).
- **Physics or wording errors.** Use the same form and name the source you
  compared against.
- **Forks.** The code is MIT-licensed. [docs/deploy-your-own.md](docs/deploy-your-own.md)
  covers deploying a fork from a clean clone.

Report security problems privately as described in [SECURITY.md](SECURITY.md),
not in a public issue.
